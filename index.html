📋 商品番号・商品名

CSVファイルから商品番号・商品名・分類など各種データを取り込み、または現在のデータをエクスポートできます。

🏷 項目編集

状態・ランキングタイプ・対応内容のアイコン / 名前 / 配色 / 並び順を変更できます。
Aa▾ を押すと配色パレットが開きます。⧉ でその配色をコピー、他の行の ⇩ で貼り付けできます。
アイコンのボタンを押すと絵文字一覧から選べます。各グループの下の ＋ 項目を追加 で項目を増やせ、🗑 で使わない項目を削除できます(使用中の商品があるときは削除できません)。
並び順は上部フィルタのボタンと、各行のドロップダウンの両方に反映されます。
※ 内部キー(右端のグレー文字)は変わらないので、名前を変えても既存データは壊れません。

画像の「◯ 選択」について

その商品でどの画像をエビデンス（証拠）として使うかを1枚だけ指定するボタンです。1商品につき1枚だけ選べます。

  • 選んだ画像が「対応内容」側で大きく表示されます。
    対応内容を「🔎 対応中-画像反映確認」または「✓ 対応済-エビデンス付」で絞ると「選択画像の右下(拡大)」列が出てきて、ここで選んだ画像の右下だけが拡大表示されます。ランキングバッジの日付が正しく反映されているか目視確認するためのものです。
  • 画像のファイル名が分かります。
    同じフィルタで出る「選択した画像」列に、選んだ画像のファイル名が表示されます。画像を差し替えるときの目印に使えます。
  • 選び直し・解除。
    別の画像を押すと自動で切り替わります。選択済みのものをもう一度押すと解除されます。
自動で選ばれることがあります
対応内容が「⏳ 把握前」の商品で行のチェックを入れると、未選択なら自動的に画像2が選ばれます（チェックを外すと解除）。「対応中に移動」ボタンでも同じく画像2が入ります。
また、対応中の商品は選んだ1枚以外が淡色化されて見分けやすくなります（マウスを乗せると元に戻ります）。

⚙ 設定

楽天アプリID・アクセスキー・店舗コードを入力してください。GitHub PATを入力するとデータがGitHubに保存され、どのPCからも同じデータが閲覧できます。

楽天Developers のアプリ一覧 →「アプリケーションID」欄の値です。
アプリ一覧の「アクセスキー」欄の目のアイコンをクリックすると表示されます。
楽天市場の店舗URLに含まれる英数字のコードです。
例：item.rakuten.co.jp/yukaiya/xxxxxxxx/
入力すると全PCでデータを共有できます。GitHubのSettings → Developer settings → Personal access tokens で発行（repo権限）。
